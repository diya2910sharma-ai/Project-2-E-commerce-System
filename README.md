# Mini Amazon 
This is a simple e-commerce system made with Python and SQLite.

It supports:

- user register and login
- browsing/searching products
- adding/removing cart items
- checkout with discount code
- order history

## How to run

1. Make sure Python is installed.
2. Open terminal in this folder.
3. Run:

python main.py

The database file `mini-amazon.db` is created automatically.
